# Cavyniq — interface demo

A non-commercial, interactive design preview with eight fictional products and AI-generated product-only images. Prices, sizes and colours are examples. There are no live offers, affiliate links, orders or payments. This is not an official Hacoo website.

Spanish is the default language; English and Russian are also available. Search, category filters, product details and device-local favourites can be explored.

This repository contains **only the compiled static demo**, not the development project, editor, credentials, working configuration or live product feed. The `main` branch root is served by GitHub Pages. `.nojekyll` disables Jekyll processing.

The demo is public. Search indexing is discouraged but the URL is not access-protected. Before any commercial launch, hosting must be reconsidered under [GitHub Pages usage limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).
